# Learning journal

One page per phase (`phase-0.md`, `phase-1.md`…), written by the project owner while building.

Suggested content for each page:

- **What I built**: a few lines.
- **New Python concepts**: each with a "in PHP I would… / in Python it is…" note.
- **What surprised me or what I got wrong**, and how I found out.
- **Open questions** to dig into later.
